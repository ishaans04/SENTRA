# SENTRA

**Stop what went wrong. Keep everything else.**

SENTRA notices when AI agents' allowed steps add up to something unsafe, pauses only the affected work, and repairs it from instructions you speak with Wispr Flow. Nothing runs until you confirm the read-back.

Everything here runs on fictional data. The tool servers are fictional and the webhook only counts deliveries; nothing outside the sandbox is contacted.

Source, documentation and the full write-up: <https://github.com/ishaans04/SENTRA>
